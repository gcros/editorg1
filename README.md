# Cria Studio AI

Projeto Android Kotlin + Jetpack Compose para criar Reels e publicações.

## Primeira versão
- Interface inicial escura com detalhes laranja.
- Seleção de vídeo da galeria.
- Seletor visual de proporção (9:16, 1:1, 16:9).
- Campo para texto/gancho.
- Pipeline inicial de exportação MP4 via AndroidX Media3 Transformer.
- GitHub Actions para gerar APK de debug.

## Próximos passos
1. Compilar e validar em dispositivo real.
2. Implementar pré-visualização e corte por início/fim.
3. Fazer a proporção escolhida alterar de verdade a composição exportada.
4. Adicionar títulos sobre o vídeo, transições, música e efeitos.
5. Implementar assistência de montagem local e serviços online opcionais.
6. Criar artes para feed, Stories e capas com exportação PNG.

Esta é uma base inicial em desenvolvimento, ainda não um substituto completo do CapCut. O build automatizado deve ser verificado no GitHub Actions antes de distribuir o APK.
